# plate-perturbation-confounders

Code for **"Plate design confounds donor variation and model evaluation in single-cell perturbation screens"**
(Ghajari, Amsaad, Prasad; Wright State University).

It contains:
- `donorvar/` — Python package (as `donorvar-0.1.0.zip`): well-aware measurement of donor-to-donor variation (pseudobulks from raw counts, inert-reference responses with equal cell numbers, cross-half size/shape estimator with well-noise correction, well noise from replicate control wells, cross-cell-type coordination with technical baselines, simulator).
- `notebooks/` — every analysis in the paper, in the order below.
- `figures/` — the figures of the paper (regenerated by `notebooks/make_figures.ipynb` and the notebooks listed below).

Data are **not** included (size and licences). The download notebooks fetch them from the original sources.

## Install

```bash
conda create -n plate-confounders python=3.12 -y
conda activate plate-confounders
cd donorvar && unzip -o donorvar-0.1.0.zip && cd ..
pip install -e "./donorvar/donorvar[test]" && pytest donorvar/donorvar      # 8 tests
pip install scanpy anndata h5py pydeseq2 matplotlib seaborn huggingface_hub mygene jupyter
```
`notebooks/Install_donorvar.ipynb` does the same from a notebook. R (with `SeuratObject` and `Matrix`) is needed only to convert the Randolph et al. Seurat object.

## Order of notebooks

| Step | Notebook | Purpose |
|---|---|---|
| 1 | `Download_parse10m` | Parse 10M PBMC cytokine data |
| 1 | `Download_op3`, `Download_scbloodnl`, `Download_Kang2018`, `Download_randolph2021`, `Download_Rhaister` | other datasets and Rhaister |
| 2 | `aim0_compass_reproduction` | pipeline validation on Replogle/Nadig (COMPASS) |
| 3 | `aim1_compass_parse` | Parse pseudobulks (cache), decomposition, controls, size/shape, corrected pipeline, interferon robustness and response size |
| 4 | `aim1_simulation` | simulations with known ground truth |
| 5 | `aim1_replication_scbloodnl`, `aim1_replication_kang_analysis`, `aim1_replication_randolph_analysis` | replication cohorts (Randolph: also response size) |
| 5 | `aquino_analysis` | Aquino et al. 2023 (222 donors): batch vs ancestry, library share, interferon shape and response size, monocytes only |
| 6 | `op3_analysis`, `op3_positive_controls` | OP3 well noise, shared-well coordination, position effects; positive controls |
| 7 | `aim1_zahid_audit` | Audit 1 (including the external 150-component space learned on Aquino et al.) |
| 8 | `op3_benchmark_audit` | Audit 2 |
| 9 | `aim1_benchmark_audit`, `rhaister_rescoring`, `state_rescoring` | Audit 3 |
| 10 | `dictionary_audit`, `dictionary_position_check`, `parse_deg_power_check` | Audit 4 (DEG counts; power and distance) |
| 11 | `inert_receptor_check` | receptor expression; strict inert set (re-run 7, 9, 10 with `INERT = ["TPO", "Megalin", "PSPN", "EPO", "EGF"]`) |
| 12 | `donorvar_parse_example` | the corrected analysis run through the package |
| 13 | `make_figures` | figures from `results/`, including the randomized-layout simulation (Figure S4) and response size (Figure S6) |

Notebooks expect to be run from the repository root, with data in `data/` and results written to `results/`.

## Data sources
- Parse 10M PBMC cytokines: https://www.parsebiosciences.com/datasets/10-million-human-pbmcs-in-a-single-experiment/ (CC BY-NC 4.0)
- OP3: GEO GSE279945; `sc_counts_reannotated_with_counts.h5ad` from the Open Problems public bucket
- 1M-scBloodNL: https://molgenis26.gcc.rug.nl/downloads/1m-scbloodnl/
- Kang et al. 2018: GEO GSE96583 (batch 2)
- Randolph et al. 2021: Zenodo 10.5281/zenodo.4273999
- Aquino et al. 2023 (POPCELL, processed scRNA-seq): Owey portal, doi:10.48802/owey.e4qn-9190, available on request from the authors; place the files in `data/aquino/`
- Replogle et al. 2022: Figshare+ (K562 essential, RPE1 raw single-cell files)
- Nadig et al. 2025: GEO GSE264667
- Rhaister: HuggingFace `tahoebio/Rhaister`, `tahoebio/parse-de-rhaister`
- State predictions: HuggingFace `arcinstitute/ST-SE-Parse`
